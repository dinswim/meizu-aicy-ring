# Aicy Ring Studio — Android-приложение для Meizu 21 Pro (без Root и без ADB)

Это готовый исходный проект Android-приложения (на Kotlin), созданный специально для **Meizu 21 Pro (Flyme AIOS)**.

## Что делает приложение:
1. **Стартовая анимация при включении Gemini и самого приложения**:
   - При каждом открытии приложения (или при запуске чата с Gemini `com.google.android.apps.bard`) запускается фирменная световая анимация 4 сегментов кольца и отправляется серия цветовых импульсов на контроллер уведомлений Aicy.
2. **Индивидуальные цвета для соцсетей (без Root)**:
   - Работает через официальный системный сервис `NotificationListenerService`.
   - Перехватывает входящие уведомления от **Telegram**, **YouTube**, **WhatsApp**, **Instagram**, **VK** и **Discord** и зажигает кольцо Aicy выбранным тобой цветом RGB и частотой мигания (`NotificationCompat.Builder.setLights(color, onMs, offMs)`).

## Как получить готовый `.apk` за 2 минуты без установки программ на ноутбук:
В проект уже встроен автосборщик **GitHub Actions** (`.github/workflows/build_apk.yml`):
1. Зарегистрируйся или войди на [github.com](https://github.com) и создай новый репозиторий.
2. Загрузи туда содержимое этой папки.
3. Перейди во вкладку **Actions** — сервер GitHub автоматически соберёт готовый установочный файл `app-debug.apk`, который ты сможешь скачать прямо на телефон!

## Как включить на Meizu 21 Pro после установки APK:
1. Открой приложение **Aicy Ring Studio** и нажми кнопку **«Выдать доступ к уведомлениям»**.
2. В настройках Flyme убедись, что включён пункт: **Настройки → Уведомления и строка состояния → Световое кольцо Aicy → Уведомления**.
